159 characters. A morning time anchor, a concrete object (the snooze
button), and a final clause that reframes a sore back as an HR case —
"filed a formal complaint with HR", "until the case is settled". Half
believable (a back going out is exactly what a boss half-believes), fresh
(no fever, no dog, no dead grandmother), and the twist lands near the end.
